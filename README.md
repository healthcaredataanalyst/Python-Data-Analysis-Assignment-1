# Python Data Analysis Assignment 1 – NumPy and Pandas

## Project Overview
This project demonstrates fundamental data analysis operations using Python libraries NumPy and Pandas. It focuses on temperature analysis, student marks processing, and transaction data exploration.

## Objectives
- Create and manipulate NumPy arrays.
- Perform numerical calculations, indexing, and slicing.
- Create and modify Pandas Series.
- Explore, filter, group, and manipulate Pandas DataFrames.

## Tools and Technologies
- Python
- NumPy
- Pandas
- Jupyter Notebook

## Key Findings
- NumPy provides efficient methods for numerical calculations and temperature analysis.
- Pandas Series supports indexing, filtering, and data manipulation.
- Pandas DataFrames enable transaction analysis using filtering, grouping, and aggregation.
- The East region recorded the highest average transaction amount (375) in the original dataset.

## Conclusion
This assignment strengthened my understanding of Python data analysis fundamentals using NumPy and Pandas. These concepts form a foundation for data cleaning, data transformation, exploratory data analysis, and future data science projects.
